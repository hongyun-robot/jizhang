## 接入判断

目前可以确认：官网存在能够返回本产品历史净值的网页内部 JSON 接口，技术上有接入基础，但未找到可以直接承诺稳定使用的发行方开放 API。主代理实测详情见下节。若需要正式数据服务，应先拿 `J07241` 与登记编码要求供应商返回样例，确认 A 份额、净值日期、单位及累计净值、历史深度、更新时效和使用授权后再确定方案。Wind 是有银行理财覆盖证据的候选；本次不能确认它已经覆盖该特定份额。

只做每日净值同步时，应保存数据截至日期并允许人工补录。公开净值不包含个人持仓、实际申赎、费用或分红记录；自动购买、赎回与账户授权属于另一项接入范围，本次没有找到这些能力的公开 API。

## 官网网页接口实测（主代理提供）

主代理于 2026-10-15 在[官方产品页](https://www.suyinwealth.com/lccs/cpxq/J07241)无需登录查看净值；点击“成立以来”观察到页面内联脚本发起以下表单请求：

```http
POST https://www.suyinwealth.com/web/fundNav/getNav
Content-Type: application/x-www-form-urlencoded

fundCode=J07241&dateType=all&rows=9999&page=1
```

浏览器实际请求由网站脚本附加 `XhC8Wb` 动态查询参数，返回 HTTP 200、`application/json`、`code=0000`，`data` 为 264 条净值记录。最新记录日期为 `2026-10-14`，`nav` 和 `tot_nav` 均为字符串 `1.02136`；最早返回记录为 `2025-09-02`。常用字段包含 `cfm_date`、`nav`、`tot_nav`、`price`、`redemption_price`。实测请求代码为 `J07241`，不要误用内部 `prd_code=Y0408Ux`。

主代理直接用 PowerShell 发送未附带网站动态参数的 POST 时，得到 HTTP 412。由此可见，可在官网页面成功使用并不等于后台裸 HTTP 调用已成立；动态校验具体机制及长期适用性尚未确认，不能把上面的请求示例作为已验证的独立接入代码。接口属于官网网页内部端点，未查到面向第三方开发者的契约、授权流程、长期限频或 SLA。

页面另有 `GET /lccs/loadNavNew` 返回 HTML 表格，主代理已验证 HTTP 200，同样观察到动态查询参数。它可以作为网页数据来源的备选研究路线；本次尚未实现采集器或生产任务。以上结果为一次实测快照，不构成可用性或更新频率保证。
