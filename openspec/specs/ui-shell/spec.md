# ui-shell Specification

## Purpose

提供单一代码库的响应式界面骨架：移动底部 Tab 与桌面侧栏双形态导航，以及暗色模式主题。

## Requirements

### Requirement: 响应式双形态导航
前端 SHALL 为一套代码的响应式应用：移动视口使用底部 Tab 导航（记一笔 / 流水 / 统计 / 我的），桌面视口使用侧栏导航；同一页面 MUST 在两种形态下功能一致。

#### Scenario: 手机访问
- **WHEN** 用手机浏览器打开站点
- **THEN** 底部展示 Tab 导航，页面单列布局，记账表单弹出数字键盘并有常用金额快捷键

#### Scenario: 桌面访问
- **WHEN** 用桌面浏览器打开站点
- **THEN** 左侧展示侧栏导航，流水列表与统计图表可利用宽屏并排展示

### Requirement: 暗色模式
系统 SHALL 支持亮色与暗色两套主题，用户可选择跟随系统或手动切换，选择 MUST 持久化在本地。

#### Scenario: 手动切换并保持
- **WHEN** 用户手动切换为暗色后刷新页面
- **THEN** 界面仍为暗色主题

#### Scenario: 跟随系统
- **WHEN** 主题设置为跟随系统且操作系统切换为深色模式
- **THEN** 界面自动切换为暗色

### Requirement: 登录页与主应用同一入口
站点 SHALL 单域名部署，登录页与主应用共享同一前端产物；未登录访问受保护路由 MUST 重定向到登录页。

#### Scenario: 未登录访问
- **WHEN** 未登录用户直接访问 /stats 路径
- **THEN** 重定向到登录页，登录后返回原目标路径
