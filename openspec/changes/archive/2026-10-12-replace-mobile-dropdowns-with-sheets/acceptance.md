# 手机选择面板验收

日期：2026-10-12。

## 交付范围

- 29 处普通选择下拉、流水分类级联、券与手工记账共用的平台 / 商家选择器均完成响应式适配。
- 小于 768px 使用底部选择面板，768px 及以上沿用原下拉。目录可搜索，短枚举直接点选；只有平台 / 商家允许创建新名称。
- 打开、重新打开、目录加载及重试均不自动聚焦文本输入。搜索与已选值分离，选择 / 清空明确回填，取消保留原值。
- 保留字段值类型、分类路径、权限、财务锁定、关联流水回填、零值和空字符串枚举。
- 父弹窗外的 `SelectionScope` 保证父内容冻结时仍能关闭浮层和使迟到创建回填失效。关闭恢复非输入焦点，键盘监听与浮层视口监听释放。
- 清理已被共用样式替代的平台专用浮层样式；手机用户列表复用原角色修改逻辑并保留最后管理员保护。

- 未运行完整后端单元 / MySQL 集成套件：没有后端或数据库实现修改；仅通过现有 Go 浏览器 fixture 启动独立服务。
- 无实体设备，iOS Safari / Android Chrome 真实软键盘尚未复核。自动化已验证非输入焦点、模拟可视区收缩、可点选列表与主操作、键盘观察器清理，不能替代实机结果。
- 未部署、未自动归档该变更。回滚仅恢复前端组件、样式及对应验收脚本，不涉及账务数据或数据库迁移。
