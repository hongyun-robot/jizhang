## Why

分类与共享资产账户目前只能由管理员维护，普通用户无法自助整理自己的记账选项，账户选择也不能像平台 / 商家一样就地创建。用户已明确要求分类和资金账户按登录账号独立，并向全部登录角色开放本人管理能力，平台 / 商家继续保持共享。

## What Changes

- **BREAKING**：分类树及资产、负债账户统一按登录账号归属隔离；名称相同也不代表同一个人的资源，管理员不能跨账号读取目录或管理账户。
- 全部有效登录角色，包括只读成员，均可创建、修改和按业务约束删除自己的分类与账户；资金流水、购券、还款、分期、预算配置及账期管理继续执行原角色限制。
- “我的”向全部登录角色提供分类管理和账户管理入口，分类保持在管理页维护。
- 业务表单的账户选项增加明确的新建操作，桌面下拉与手机选择浮层都可打开账户创建表单，成功后选中真实账户 ID，保留父表单草稿。
- 按个人账户范围同步约束流水、券、周期模板、统计与预算进度，防止仅隔离选项列表而通过引用或聚合访问他人的账户数据。
- 迁移旧共享资产与分类，保留资金账户身份、期初余额和历史财务金额；为各账号建立独立分类副本及零余额默认资产账户，明确无法唯一判断的历史归属与回滚限制。
- 平台 / 商家目录的共享、名称去重、文本接口和创建逻辑保持现有行为；账户创建借鉴其交互与登录权限，资金账户不会按名称合并余额。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `categories`：个人分类树、一次初始化、本人管理与引用保护。
- `accounts`：资产与负债统一归属、个人默认账户、账户选项内创建与历史迁移。
- `identity/access-control`：分类 / 账户脱离管理员设置权限，角色权限与个人资源归属共同执行。
- `ui-shell`：“我的”管理入口、账户字段创建能力及嵌套表单交互。
- `transactions`：个人资源引用、查询 / 导出与历史跨账号关联的兼容规则。
- `statistics`：收支与资产聚合按本人账户范围计算，缓存按登录账号隔离。
- `budgets`：个人分类预算匹配、本人消费进度与提醒，保留管理员配置和账本总预算结构。
- `recurring-entries`：模板管理及自动生成不得绕过账户与分类的本人归属。
- `vouchers`：券可见范围和操作同时校验支付账户归属，平台 / 商家仍共享。
- `notifications`：全部提醒按归属隔离列表、未读数、已读操作及后台生成结果。

## Impact

- 后端：`account_ownership.go`、分类服务 / 仓储 / 处理器、权限函数与路由，以及流水、券、周期任务、统计、预算和提醒的资源范围校验。
- 数据库：沿用 `accounts.owner_id` 扩展资产归属；增加分类归属、迁移映射与个人目录初始化支持，账户创建增加请求幂等支持。需成对 SQL 迁移及备份、迁移前后对账和回滚说明。
- 前端：`Mine.tsx`、`App.tsx`、导航与权限工具、账户管理表单及记账 / 转账 / 购券 / 周期记账 / 负债表单的账户选择器；筛选器仍仅选择已有资源。
- API：保留账户与分类的既有地址及数值 ID；成功列表缩小为本人范围，越权 ID 返回 403，未登录返回 401；创建账户支持请求标识。旧客户端引用他人资源的请求不再接受。
- 验证：补充四档角色、跨账号隔离、迁移资金守恒、创建重试及桌面 / 手机表单生命周期验收；更新现有“账户不能创建”“成员不能创建资产”的测试与 README。
