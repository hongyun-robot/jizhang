## 已实现

- `000018_bank_wealth_accounts` 成对迁移及独立 model/repository/service/handler；只种苏银 J07241 / Z7003125000238 / CNY 元数据。普通账户新增 wealth，现金期初只能为零，支持统一排序、停用、财务历史防删除/改类。
- 期初、首次及追加申购、跨日付款/确认、部分/全部赎回、净应收及实际到账、现金分红和实际再投资；加权成本、清仓尾差、费用只计一次。LedgerWrite 内原子写事件、现金、mutation、审计；请求重试不重复资金，末笔及 settlement 依赖撤销保留历史。
- 个人资源按认证 owner 隔离，管理员不能越权；全部角色可维护本人账户/合法期初/人工净值，资金操作受既有角色和创建人规则保护。已封账确认不允许修改，旧期确认作为只读来源时可在新开放期到账。
- 公共自动净值修订、本人跨账户补录/更正/撤回、预期版本与请求幂等、自动同日优先和来源切换审计。合并序列引用完整 source/record/revision 和个人序列版本，重建清理撤回日期和后继区间；派生失败不改变成功财务回执，随后恢复不再扣现金。
- 当前/历史/账户/首页/曲线共用估值口径。缺价返回 null 与不完整状态，已知小计包含应收；清仓仍保留应收。累计净值不作估值，不用今天价或当前份额倒填历史，不用旧价格掩盖金额越界。
- 北京时间 08/12/18/22 四槽、持久化租约和漏槽合并、冷却、过期租约恢复、状态和成功/尝试时间；普通读取不访问银行，单产品失败不阻断其他产品。人工补值只失效本人缓存，公共更新按持久归属更新所有相关账号。
- `/wealth`、`/wealth/:id`、`/wealth-positions/:id` 独立页面、受控下拉、真实事件表单、中文响应式日期/账户选择、净值/补录/审计和来源日期；支持只读成员补值、冲突保留草稿、换号迟到回执隔离、关联资金流水/CSV/事件导航。表单默认日期使用北京时间。
- 普通“记一笔”已移除黄金买卖，独立黄金买卖保持；没有新增理财快捷记账模式。生活收入、支出、分类、预算与封账收支不计理财本金、费用、分红或估值损益。
- `wealth-admit` 默认校验完整真实采样清单并保存摘要，用户 API 不能更改目录准入。待验证、退休及未知产品拒绝新持仓/申购；既有产品历史、处置和补值继续保留。本次 J07241 开放为单独记录的用户授权运维例外，没有伪造采样清单或放宽通用校验代码。
