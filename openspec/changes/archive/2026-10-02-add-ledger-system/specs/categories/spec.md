# Spec Delta

## Purpose

提供账本级自定义的两级收支分类树，作为记账归类与统计聚合的维度基础。

## ADDED Requirements

### Requirement: 两级分类结构
系统 SHALL 支持两级分类（父分类与子分类），收入与支出各维护一套独立分类树；记账时 MUST 关联一个末级分类，无子分类的一级分类可直接作为末级。

#### Scenario: 记账选择分类
- **WHEN** 用户记录支出并选择"餐饮 → 外卖"
- **THEN** 流水归入"外卖"，按一级分类"餐饮"聚合的统计包含该笔金额

### Requirement: 默认种子分类
新账本 SHALL 自动创建一套默认两级分类（如 餐饮/交通/购物/居家 等），默认分类可重命名、可删除、可新增。

#### Scenario: 新增分类
- **WHEN** 管理员新增一级分类"宠物"及其子分类"粮食"
- **THEN** 记账时可选到"宠物 → 粮食"

### Requirement: 分类删除约束
被流水引用的分类 MUST 不可删除，拥有子分类的分类 MUST 不可直接删除（须先处理子分类）。

#### Scenario: 删除被引用的分类
- **WHEN** 管理员删除仍有流水关联的分类
- **THEN** 操作被拒绝并提示存在关联流水
