## MODIFIED Requirements

### Requirement: 设置类操作仅限管理员
账期结算日配置、封账与解封、分类管理、共享资产账户管理、预算配置、用户与角色管理 SHALL 仅管理员可操作；其他角色执行时 MUST 返回 403。个人负债账户的资料、账单日期和启停 SHALL 按 `accounts` 能力的本人归属规则开放给其所属登录账号，包含只读成员；此例外 MUST NOT 授予还款、分期或其他资金写权限，管理员 MUST NOT 因角色绕过其他账号的个人负债归属。周期记账模板管理不适用本条，按 `recurring-entries` 能力中「按创建者归属隔离」的规则执行。

#### Scenario: 记账员修改账期设置
- **WHEN** 记账员调用修改结算日的接口
- **THEN** 返回 403，设置不发生变化

#### Scenario: 普通成员修改分类
- **WHEN** 普通成员尝试新增或删除分类
- **THEN** 返回 403

#### Scenario: 只读成员设置自己的负债账户
- **WHEN** 只读成员修改本人负债账户的名称、账单日期或启停状态
- **THEN** 按既有账户规则允许保存，但不提供还款或创建分期等资金操作入口

#### Scenario: 管理员管理其他人的负债账户
- **WHEN** 管理员尝试访问或修改另一个账号的个人负债账户
- **THEN** 返回 403，管理员的前端入口也不将该账户列为可管理资源

### Requirement: 查看权限对全员开放
四档角色 SHALL 均可查看账本内按既有资源归属允许访问的流水、共享资产账户、分类、预算、提醒与统计数据；个人负债账户及其明细 MUST 按 `accounts` 能力仅向所属登录账号开放，不因管理员角色扩大查看范围。只读角色在相同归属范围内 SHALL 获得与其他角色一致的查看能力。平台 / 商家选项目录的读取与创建 SHALL 按 `voucher-platform-options` 能力对全部已登录角色开放，包含只读角色；该非账务目录创建能力 MUST 不授予券、流水或其他受限资源的写入权限。

#### Scenario: 只读成员查看统计
- **WHEN** 只读成员打开统计页
- **THEN** 看到在相同资源归属范围内与其他角色一致的完整数据

#### Scenario: 只读成员创建非账务选项
- **WHEN** 只读成员创建平台 / 商家选项后尝试登记购券或记账
- **THEN** 选项创建成功，购券与记账请求仍返回 403，账户余额、消费和预算不变化

#### Scenario: 个人负债查看隔离
- **WHEN** 任一角色查询账户与负债列表
- **THEN** 仅包含其可查看的共享资产与本人个人负债，不出现其他账号的个人负债账户或详情

### Requirement: API 与界面双重执行
权限 MUST 同时体现在服务端 API 拒绝（403）与前端入口隐藏或禁用两处，界面隐藏 MUST NOT 作为唯一防线。首页、流水页及各业务表单 SHALL 使用一致的角色与资源归属语义，只读成员 MUST 不出现普通记账、购券、还款或分期提交入口；本人负债资料管理与平台 / 商家目录创建 SHALL 按各自能力保留。

#### Scenario: 直接调用高权限 API
- **WHEN** 只读成员绕过界面直接调用记账接口
- **THEN** 服务端返回 403，数据不发生变化

#### Scenario: 只读成员浏览记账入口
- **WHEN** 只读成员查看首页和流水页
- **THEN** 可查看数据与导出，但不显示快捷记账、记一笔或购券提交入口

#### Scenario: 成员查看他人普通流水
- **WHEN** 普通成员查看创建人为其他用户的普通流水
- **THEN** 不显示编辑与删除入口，管理员和记账员按既有权限及资源保护规则展示操作
