## ADDED Requirements

### Requirement: 个人黄金配置与资金权限分离
全部有效登录角色 SHALL 可查看、创建和配置本人黄金账户，按 `gold-accounts` 规则录入或合法更正期初，并手动刷新本人可访问产品的公开报价。黄金买入、卖出及其修正或撤销 MUST 沿用流水写入资格和创建人权限，只读成员 MUST 无资金写权限。账户、事件、持仓、现金账户及审计读取 MUST 同时校验本人归属，管理员及记账员不得跨账号，owner_id MUST 从认证身份确定。公共报价共享与后台更新 MUST 不授予另一账号的个人数据访问权，界面和 API SHALL 双重执行。

#### Scenario: 只读成员建立期初但不能买卖
- **WHEN** 只读成员创建本人黄金账户并录入合法期初，随后直接调用买入或卖出接口
- **THEN** 账户和期初可保存，买卖接口返回 403 且前端不提供提交入口，现金和交易不变

#### Scenario: 管理员不能查询他人持仓
- **WHEN** 管理员使用其他账号黄金账户 ID 查询持仓、事件、估值、审计或提交买卖
- **THEN** 返回 403，公共价格可共享但他人账户及资金数据不返回

#### Scenario: 后台独立使用持久化归属
- **WHEN** 无用户在线或甲触发手动刷新后新报价需更新所有黄金持仓
- **THEN** 各持仓按自身归属更新估值，甲响应只含其有权读取的数据，不借甲身份操作乙的资金
