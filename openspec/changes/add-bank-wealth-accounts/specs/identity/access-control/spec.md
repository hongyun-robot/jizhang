## ADDED Requirements

### Requirement: 本人银行理财配置和人工净值与资金权限分离
全部有效登录角色，包括只读成员，SHALL 可查看并配置本人银行理财账户、按历史及封账约束录入或合法更正期初、刷新可访问产品净值，以及按 `wealth-accounts` 维护本人的人工补值和审计。申购、赎回、现金分红、再投资、实际到账与资金事件修正/撤销 MUST 执行既有流水写入资格及创建人权限，只读成员不得资金写入。账户、持仓、事件、应收、关联现金、补值及审计 MUST 按本人隔离，管理员及记账员不得越权。owner_id SHALL 从认证身份取得，不信任客户端参数；界面和 API SHALL 同时执行。公开行情共享和后台重估 MUST 不返回或改写另一账号个人资料，人工补值仅本人产品范围共用。

#### Scenario: 只读成员补净值但不能申购
- **WHEN** 只读成员为本人已登记产品补录缺失日期，再直接调用申购或到账 API
- **THEN** 合法补值保存且仅重估本人持仓，资金接口返回 403，现金和交易不变化

#### Scenario: 管理员访问他人资料
- **WHEN** 管理员提交另一账号的持仓、现金账户、人工补值或审计标识
- **THEN** 返回 403，不泄露或修改目标资料，不能借公共产品身份取得个人访问权

#### Scenario: 后台自动值替代个人补值
- **WHEN** 甲触发共享净值刷新后后台需要更新甲乙的相关持仓
- **THEN** 按各持仓持久化归属更新并分别失效缓存，甲响应不包含乙持仓、补值或资金详情
