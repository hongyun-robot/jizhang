# 配置化产品与理财零钱实现验收

日期：2026-10-16。对应本变更任务 12.1–12.2、13.1–13.4。

## 实现

- `wealthdata/products.json` 是唯一维护的产品清单，严格校验身份、币种、日期、估值及策略。`Source.Fetch` 接收完整元数据，苏银/民生按银行复用取数；服务按策略配置执行订单规则。采集器副本通过 `go generate` 生成，并有一致性测试。
- `cmd/wealth-catalog` 只生成公开元数据或待审核 INSERT，不连库、不自动开放；同银行新增份额的路由及原生民生适配器均通过新增配置测试，无业务代码分支。
- `wealth_cash` 是可支付现金子类。启用现有普通账户保留账户 ID、期初、普通流水和排序，只增加本人产品关联。账户及理财页面使用同一账本，不建立另一份独立持仓。普通支付选择器共用现金能力判定。
- 复用原有净值槽与补偿服务，包含只有理财零钱引用的产品。来源、个人资金和净值计算分离；保存转入确认日、申请时间、快转/普通转出权益时点，支持一笔转账两侧的时点元数据。
- 余利宝默认快转，待确认资金优先、同类后进先出；实际确认日优先于可修正估算。收益按实际披露日期汇总入流水，正、负和零均可核对；跨未单独披露日期只内部插值，不伪造公开净值。
- 收益、专用流水和审计在 `LedgerWrite` 内原子提交。采用值可从流水或详情修改，支持余额校准、重复回执和并发版本冲突。手动区间后补发净值不重复计收益。普通修改/删除/关联退款不能绕过收益入口。
- 投资收益改变账户与资产曲线，不混入生活收入、消费和预算。封账期不改资金流水，显示待核对并在重开后重算；除息线索显示分红待核对。停止联动保留历史。

规则的官网地址、版本和估算边界记录于 [规则研究](../../../docs/research/yulibao-premium-20250715.md)、[操作与接入说明](../../../docs/wealth-products.md)。确认日未提供时不是银行已确认事实；实际可用余额、快转限额及交易确认由用户核对。基准日结束时的核对余额按已确认资金起算。

## 数据库

新增成对迁移 `000021_wealth_cash_accounts`，增加现金子类、产品关联、时点、收益、审计和受管理流水来源，包含本人复合外键和唯一约束。不创建个人账户、持仓、余额或默认关联。

MySQL 验收覆盖 up/down/up，保留既有资金、并发重复配置/修订/补偿、过期版本、跨 owner 外键拒绝、正→零→负流水转换、余额校准、非法时点整笔回滚、封账后入账及重开、删除原转账后收益重算。有任一配置/时点/收益/审计时 down 在删除前拒绝，包括已停用联动的历史。验收发现并修复了复合外键自动索引在 down 后残留的问题，最终使用显式索引并配对删除。

迁移前须备份真实财务库；有历史时采用保留数据的前向修复。本地实施阶段只在随机临时库和内存账本运行迁移。随后按用户明确请求完成生产发布、备份及 19→21 升级和真实净值/后台收益验收，见 [生产发布记录](wealth-cash-production-2026-10-16.md)；真实余利宝账户由本人选择基准日启用。
