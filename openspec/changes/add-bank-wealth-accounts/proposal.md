## Why

现有现金、场外基金和黄金账户无法准确承载银行理财产品的份额、跨日申赎与净值估值。苏银理财 J07241 已验证官网净值数据来源，需要在无人值守采集验收通过后接入，并在延迟披露时允许本人补录缺失净值，使资产与资金往来可核对。

## What Changes

2026-10-16 用户明确调整：J07241 提前开放选择，不等待三天采样结束。此产品级授权例外见 `admission-2026-10-16.md`，不改变三天验收标准及其未通过状态；下述默认准入顺序对其他产品继续适用。

- 新增本人银行理财账户，一个账户管理多款产品；产品只能从已接入目录下拉选择，首批为苏银理财恒源日申周赎1号A（J07241），后续逐个验证接入。
- 支持期初持仓、实际确认的申购与赎回、跨日付款/份额生效/到账、分红应收、现金分红及实际红利再投资；按加权平均成本核算持仓、已实现及累计盈亏，沿用审计、末笔撤销、幂等与封账保护。
- 北京时间每天 08:00、12:00、18:00、22:00 后台同步共享公开净值，启动恢复漏跑任务，提供合并限频的手动刷新。普通页面只读缓存，接口失败与尚无新净值分别展示；无人值守采集必须验收通过才开放产品选择，人工补录不能替代此门槛。
- 缺净值仍可保存真实持仓和交易；有旧值沿用并标明日期，无值显示未知及总资产不完整，不用零、成本或累计净值冒充单位净值。
- 人工净值按本人、产品、日期保存，本人跨账户共用且仅补缺失日期；同日自动有效净值优先。全部有效角色可维护本人的补录，允许留痕更正或撤回；自动同日值到齐后原补录仅供审计。估值可重算已封账历史，不能改变资金、份额、成本及封账收支。
- 理财市值、待结算资金进入账户、首页和逐日资产走势，所有投资本金、损益、分红与费用不进入生活收支或预算。
- 理财仅在独立页面操作，不加入“记一笔”；移除“记一笔”弹窗中的黄金买卖模式，保留独立黄金页面的买卖、报价和历史功能。
- **BREAKING（账户响应扩展）**：增加 `asset_class=wealth`，非零理财持仓无有效净值时 `balance` 为 `null`；客户端需识别新子类和不完整估值。黄金快捷入口按上述范围移除，原交易 API 与财务数据不变。

首版仅支持已接入的人民币单位净值型银行理财，不支持任意代码、其他份额冒用、货币型万份收益产品、银行自动下单、银行个人账户/交易拉取、公共人工改价。期初与真实交易由本人录入。

## Capabilities

### New Capabilities

- `wealth-accounts`: 产品准入目录、本人多产品持仓、实际跨日交易与分红、成本及盈亏、苏银净值适配与每日同步、本人补录及有效净值合并、独立理财页面。

### Modified Capabilities

- `accounts`: 新理财资产子类、未知余额、支付隔离、生命周期、排序和市值汇总。
- `transactions`: 理财事件管理的现金转账及其保护、展示、导航和导出。
- `statistics`: 理财历史估值、个人补录隔离、来源切换重建、缓存失效和投资口径隔离。
- `home-dashboard`: 首页理财资产与不完整状态；快捷记账移除黄金且不加入理财。
- `gold-accounts`: 黄金买卖统一在独立黄金页面，移除快捷弹窗入口要求。
- `identity/access-control`: 本人账户/期初/人工净值管理与资金交易权限分离。
- `billing-periods`: 理财财务事件的硬锁与自动/人工估值修订的边界。

## Impact

- 后端：新增理财 model/repository/service/handler 与来源适配器，接入账户聚合、资金写入、路由、启动任务和统计；复用基金核算与持久化任务模式，不能将 J07241 塞入要求 `.OF` 身份的场外基金接口。

- 运行环境：现有 Go Alpine 容器没有浏览器运行时；动态校验的匿名采集方案须先在目标环境验证，必要时增加隔离的浏览器采集进程及 Compose 配置，不依赖桌面工具或用户登录会话。
- 前端：理财独立路由、产品下拉、账户/持仓详情、事件与补录表单、行情来源/日期/异常、总资产空值与换号缓存；移除 `TxnFormModal.tsx` 中黄金模式，保留 `Gold.tsx` 操作入口。
- 验证与文档：覆盖资金和跨日守恒、权限/封账/并发重试、人工值切换及撤回、历史修订、无人值守与故障恢复、桌面/移动验收。迁移 `frontend/e2e/gold.mjs` 的快捷买入场景并保留其幂等断言；更新 README。已知接口证据与限制见 `docs/research/suyin-wealth-api.md`。
