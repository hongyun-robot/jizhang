# Spec Delta

## ADDED Requirements

### Requirement: 窄视口操作可达
分类管理页 MUST 在任意视口宽度下完整呈现每个分类的全部操作（重命名、删除、新增、子分类管理），MUST NOT 因容器宽度不足被裁切为不可见或不可点。

#### Scenario: 手机打开分类管理
- **WHEN** 在 360px 视口打开分类管理页
- **THEN** 每个一级与子分类的重命名、删除按钮完整可见可点，无横向溢出裁切

#### Scenario: 中等视口（平板窄屏）
- **WHEN** 在 480–767px 视口打开分类管理页
- **THEN** 分类卡片单列排布，卡片内操作全部位于可视区域内

#### Scenario: 桌面布局保持
- **WHEN** 在 ≥992px 视口打开分类管理页
- **THEN** 双列/多列卡片排布与既有桌面布局一致
