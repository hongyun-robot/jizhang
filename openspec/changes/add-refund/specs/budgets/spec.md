# Spec Delta

## MODIFIED Requirements

### Requirement: 预算消耗计算
预算消耗 SHALL 为该账期内计入对应范围的支出流水合计减去同期退款流水合计（退款按到账日归入账期、按其关联或归属分类累计）；收入与转账 MUST NOT 计入消耗；分类预算仅累计该一级分类及其全部子分类的支出与退款净额。

#### Scenario: 计算分类消耗
- **WHEN** 本期"餐饮"子分类支出累计 3200 元
- **THEN** 餐饮预算进度按 3200/3000 计算，显示为已超支 200 元

#### Scenario: 退款回吐消耗
- **WHEN** 本期餐饮支出 1000 元、退款到账 200 元
- **THEN** 餐饮预算消耗按 800 元计算

### Requirement: 进度与超支展示
预算 SHALL 以进度条展示已消耗比例；超支时 MUST 标红并显示超出金额，且 MUST 触发一次本期站内超支提醒（同一账期同一预算不重复提醒）；净消耗为负时 SHALL 显示"本月已退回 ¥x"文案且进度条不渲染负宽度。

#### Scenario: 超支标红与提醒
- **WHEN** 某分类消耗首次超过其预算
- **THEN** 进度条标红显示超出金额，并生成一条超支站内提醒

#### Scenario: 净消耗为负
- **WHEN** 本期"数码"分类尚无支出但有 200 元退款到账
- **THEN** 该分类展示"本月已退回 ¥200"，进度条宽度为 0
