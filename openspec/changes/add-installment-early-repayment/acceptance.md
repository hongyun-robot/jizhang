## 实现结果

- 连续一期、多期或全部剩余期数按真实未还本金及未付手续费一次偿清；报价锁定金额，拒绝跳期、部分金额、费用单独偿还及旧手填结清费用。
- 尚未入账费用在实际还款日按期生成独立支出，统一由本次还款资产账户承担；有效费用绑定期次，原计划日期保留，未来补齐不会重复收费。已支付、退款冲减、取消费用按实际剩余处理。
- 普通还款、分配、通用转账和所有资金写入执行完整分配规则；不提供待抵扣或溢缴。真实退款单独处理，无法完全冲减的负债退款、收入或超额资金整体回滚。
- 新操作记录保存期次、资金来源及不可变金额/日期快照，支持同计划连续操作及多计划普通偿付的专门逆序撤销；普通删除、旧还款撤销不能绕过后继保护。
- 新 API 启动前执行历史资金检查；只读核验命令不变更记录。有真实历史未分配资金时保留旧版本核对后再切换，账户负余额也不能跳过检查。
- 复用现有数据结构，无新增 SQL 迁移，无删除旧审计字段。README 说明了真实返还的精确分配、同步发布、备份和新操作执行后的降级限制。
